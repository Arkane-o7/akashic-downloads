# Akashic downloads

Installers and installation notes for [Akashic](https://akashic-jet.vercel.app/), a personal AI desktop app.

Use the website or the [Releases page](https://github.com/Arkane-o7/akashic-downloads/releases) to find downloads. Each release includes installation notes and a SHA-256 checksum.

The first macOS build is an **unsigned developer preview** for **macOS 12+ on Apple Silicon**. It is not Developer ID signed or notarized by Apple; macOS may block its first launch. Read the release's limitations before installing. Clean-Mac/live-provider validation and bundled-asset provenance review remain open. Automatic updates are not configured.

Akashic builds on [Hermes Agent](https://github.com/NousResearch/hermes-agent) by Nous Research and its contributors. The app retains the Hermes MIT licence and third-party notices.
